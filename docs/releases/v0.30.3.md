# v0.30.3 — After a session closes, the selection stays in its project

A patch release: one fix and a keyboard shortcut for a dialog that already exists. `terminum upgrade`
brings it. A patch rather than a minor: no new screen, and nothing changes in the protocol or the
install.

## Fixed

- **The selection jumped to an unrelated session when the shown one closed.** The page took the
  first row of terminumd's own list, which has neither the projects on top nor the order of the
  groups in your browser. Now it shows:
  1. the first session of the same project;
  2. outside projects, the first session of the same tmux group;
  3. when that was the last one, the session at the top of the list as drawn.

  A project whose only session closed leaves the list and `projects.json`, as it did before.

## New

- **⌘Enter or Ctrl+Enter** in the Paste dialog is Send, like the Bookmark, Reminder and Ask dialogs
  since v0.30.2; a plain Enter is still a new line.

## Verified

`make check` passes: Rust tests, clippy, the Panel's browser check, `web/test/e2e_live.mjs`, and
the Page's browser checks in Chromium and WebKit, plus `scripts/security_check.sh`.

- New checks against a fake terminumd, in both engines at both sizes, with terminumd's two possible
  orders of messages. Run on the old choice of session in Chromium, 8 of 14 fail, and the selection
  goes to terminumd's first row.
- A new live check against a real terminumd and a private tmux, in Chromium and WebKit, kills real
  panes in tmux: the selection moves to the project's first session, then to the top of the list when
  the project's only session closes, and the project leaves the list and `projects.json`.
- Reviewed with /simplify, and its fixes are in:
  - the drawing and the choice of the next session now read one rule for what a project and a group
    list, and one list order;
  - a group's menu reads the same parts of the list.

Not verified:
- the owner's own projects and browser;
- sessions on remote hosts: the rule is the same for them, and only a local tmux was closed.

Known and left as it is: terminumd says that a member left its project before it sends the list
without that pane, so a closed session's row can stand for a moment in its tmux group.
