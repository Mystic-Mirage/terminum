# v0.27.0 — the sign-in stays in the browser; Diagnostics for bug reports

A minor release: the page's and the Files panel's sign-in changed (a protocol change), and a new
item in a row's menu. `terminum upgrade` brings it; open pages reload themselves and stay signed in.

## Security

- **The page never sends its sign-in's secret again.** After one proof that terminumd knows the
  sign-in, the page and the Files panel sent the 30-day secret on every request until one failed.
  A request made between terminumd letting go of its port and the page noticing could hand the
  secret to whatever listened there next (where launchd does not hold the port: before the agent
  is loaded, with `TM_NO_LAUNCHD`, on Linux, in tests). Now `/api/hello` also names the running
  terminumd's `boot` (256 random bits drawn at start), and requests carry an HMAC of the sign-in's
  proof key and that boot: the next terminumd, of another boot, refuses it, so a program that took
  the port learns nothing it can use. A page loaded across an upgrade proves the new terminumd and
  sends the refused request once more; Sign out reaches the sign-in it meant then too. terminumd
  refuses the secret itself from a browser that sends `Sec-Fetch-Site`, so a page that sent it
  would fail at once instead of leaking it unseen. Still open, as before: a program that serves
  its own page on the port while terminumd is down can read the sign-in from the browser's
  storage (SECURITY.md).

## New

- **Diagnostics… in a row's menu.** The pane's tmux fields (size, cursor, alternate screen, mouse
  modes, command, folder) with the build, browser and row, in the Last Lines window, ready to copy
  into a bug report; it reminds you to check folder, host and title before sharing.

## Fixed

- **Keys after Ask.** After a Shift selection in a full-screen program (Claude Code's fullscreen
  TUI), closing the Ask dialog (Send to Agent, Cancel, Esc) left the keys on the page: typing did
  nothing until another session was shown. The keys go back to the terminal however the dialog
  closes.
- **Sent history hides more secrets and fewer words.** `API_KEY = "abc"`, `:=`/`?=` assignments,
  `X-API-Key: abc` and compact JSON `{"password":"a b"}` are redacted; `go_to_kennel`,
  `tokens:5` and `secrets-manager:latest` stay as typed.
- **Remote hosts.** ssh links get `ConnectTimeout=10` unless your ssh config sets one, so a host
  that never answers says "ssh: no answer from the host" instead of hanging; a host whose recipe
  changed keeps its link until the new one answers, and shows why.
- **Copies and tables.** A program's copy (OSC 52) is taken only on a left-button release; a pipe
  table's rows cut short stay rows, and a one-cell `|-- src` line after it ends it.
- **Smaller things.** The project menu says New Window; a bookmark on a full-screen program's
  screen says why it cannot be found again; the bookmark dialog shows terminumd's kept length;
  invisible characters follow one rule in hot keys, short names, restored titles and session
  names; `terminum` commands end their whole child on Ctrl-C or a timeout.

## For contributors

- Each test run takes a free port and its own tmux socket, and the Node e2e checks end their
  terminumd, tmux and folders when stopped by a signal too; `scripts/worktree.py` gives each
  task its own worktree; `make check` records a pass per tree; a release refuses compiler
  warnings; commits are scanned for leaks (`make hooks`); flaky timing checks (webMotion, touch,
  seltext, bench_ls, the foot's and the menus' motion, two live checks) wait for what they test,
  and motion is stepped through instead of sampled frame by frame; `web/test/e2e_liveprogs.mjs`
  checks vim, mc and Claude Code in both of its TUIs for real.

## Verified

At release, on the delivered tree after `/simplify` over every change since v0.26.4 (its fixes
applied: one sign-in protocol module for the page and the Files panel, one ssh command for every
host link, Denial as a response, Sign out learning from the revoke, the review scripts' sockets
named by testrun) and two pragmatic reviews of the sign-in change (the design: a per-boot
credential instead of a challenge and a token store, the narrower claim, the secret refused from
browsers; the code: each request uses the credential of the proof it waited for, a stale Sign out
is proved again): `make check` passes (698 Rust tests, 69 Python, 51 UI and 157 Page unit tests,
clippy, the Panel's browser check 167/167, `web/test/e2e_live.mjs` 223/223 with vim, mc and Claude
Code in a private tmux, the Page's browser checks 1615/1615 in Chromium and WebKit at a wide and a
phone size, `scripts/security_check.sh`); `scripts/e2e_remote.py` 37/37 for the host links.

Noticed, not fixed: a program that serves its own page on terminumd's port can still read the
stored sign-in (a non-extractable key instead is a follow-up); a 404 `unknown_signin` from an
unproven server still drops the sign-in (the form shows either way); `ssh -G`'s answer is kept
until terminumd restarts.

Not verified: a physical iPhone, and the user's own signed-in Safari (the sign-in change was
checked in Chromium and WebKit, against a private terminumd and a fake one).
