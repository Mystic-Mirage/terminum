# v0.31.0 — Filters for notes, tables as pictures, and no silent stops

A minor release: new features, and the messages between terminumd and the page changed.
`terminum upgrade` brings it.

## New

- **A session that stopped and needs you says so.** A turn that ends with a question, in any script's
  question mark, with Codex's `request_user_input_async`, with Claude Code's "Session paused", or on a
  program's own safety line, shows the flashing amber ? and a reminder, as a question asked mid-turn
  does. Only one bit of the last message leaves the hook's process, never its text. A failed session
  gets a reminder too. A stop in plain words with no question mark gets Unread only.
- **The bookmarks' and reminders' panes filter:** by session, project or all, and by everything,
  reminders or bookmarks.
- **A table as a picture:** PNG beside Copy on a table widget, in the shown theme's colors.
- **Other languages in code blocks:** Gherkin and other fenced starters, and an unclosed fence no longer
  stops what follows from rendering.
- **Agents tidy their own notes.** Full create, read, update and delete of a session's records, for its
  own session only. A reminder is for a question only, a record can replace others, a session keeps three
  reports, and each new record answers with the session's other open ones so the agent closes what it
  covered.
- **One order for projects and tmux groups,** moved past each other by the menus and a drag.

## Changed

- New Window is one plain [+] for projects and groups, first among a header's buttons. A dot beside the
  name marks a project, a thin >_ a tmux session. Bookmarks' and reminders' waves stand at a row's right.
- The settings button is a cog and its menu opens under it, on a computer.
- A paste Claude Code folds into `[Pasted text #1 +6 lines]` is pasted once more, so you see the text.
- A row's subagent count stands beside a bot icon, and counts the team Claude Code lists under its footer.
- A blocked step in the plan is a large "!".
- Every dialog stays in the middle of the window as it is resized.
- `make install` first brings a clean `main` up to `origin/main`, and refuses one behind with uncommitted
  changes (`TM_INSTALL_STALE=1` installs it as it is).

## Fixed

- **Unread was lost for good** after a subagent was interrupted, killed or failed: neither program sends
  an end for it, so every later turn in that pane waited on it. A turn with no Stop now ends by its screen.
- **"Sized for another screen: tmux exited" over a local pane.** A resize that failed named the pane shown
  by then, not the one it was for. It now names its own, and reads "tmux did not resize this pane: …".
- Backspace over a selection in Claude Code's input deleted nothing when it ended past the text.
- A table lost its head or flashed; a table with its first rows gone from tmux stayed text.
- "This pane has closed" on a live pane under load: the pane's view asks tmux's list before it gives up.

## Known

"This pane has closed" still came once in about four full live runs, right after terminumd's restart
checks, and its cause is not found. The next three runs, with logs, were clean.

## Verified

`make check` passes: Rust tests, clippy, the Panel's browser check, `web/test/e2e_live.mjs`, and the Page's
browser checks in Chromium and WebKit, plus `scripts/security_check.sh`. Also `scripts/e2e_hooks.py` 41/41,
`scripts/e2e_sizestale.py` 3/3, `scripts/e2e_install.sh`, and the real Claude Code in both of its TUIs for
pastes and for Backspace.

Not verified: how Codex and Claude Code end their turns was read from their source and program, not seen
in a live session with a model. Real Safari, an iPhone and a signed-in page were not checked. A table's
PNG pasted from real Safari was not tried.
