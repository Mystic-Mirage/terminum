# v0.27.3 — Shift+Insert and Ctrl+Insert, a wider Bookmark dialog, a mark for agents in full screen

A patch release: small changes to existing screens and one fix. `terminum upgrade` brings it.

## Changed

- **Shift+Insert pastes and Ctrl+Insert copies** in a Linux or Windows browser, as in xterm and
  Windows; they went to the program as `ESC[2;2~` and `ESC[2;5~`. Settings' "Shift+Insert and
  Ctrl+Insert paste and copy" (on by default, kept in this browser) sends them to the program
  again. On a Mac nothing changes: there a PC keyboard's Insert is Help. A contribution
  (#7).
- **The Bookmark dialog** is 80% of the terminal's width (480 px at least), so a long selection
  and its note no longer sit in a narrow column.
- **The bookmarks' and reminders' pane** puts where and when (another session's name, the time,
  "up now") on a line of its own over each title, 1 px larger, so the title has the whole row.
- **A coding agent in its own full-screen TUI** (Claude Code with `"tui": "fullscreen"`) gets a
  small orange ! beside the header's full-screen mark: terminum hides the history and the
  widgets while a pane is in full screen, so it says to turn that mode off (on hover; a press
  shows it as a toast, for a phone). A program's full screen (vim, mc) has none.

## Fixed

- **A bookmark's wavy line stayed after Claude Code's /clear**, in the terminal's left gutter
  over blank rows. /clear draws the screen anew but leaves tmux's history, so the page kept the
  mark over whatever rows stood there. The line now goes with its text and comes back when the
  text is on its line again.

## Verified

`make check` passes (699 Rust tests, Python, UI and Page unit tests, clippy, the Panel's browser
check 167/167, `web/test/e2e_live.mjs` 231/231 with vim, mc and Claude Code in both of its TUIs:
the ! beside real Claude Code's fullscreen TUI and none beside vim, the Page's browser checks
1633/1633 in Chromium and WebKit at a wide and a phone size, `scripts/security_check.sh`). The
/clear check fails on the code before the fix (the wavy line stayed); the header, the dialog and the pane were looked at in Chromium and WebKit at
1400×900 and 390×844, dark and light. PR #7 was reviewed before the merge: no network, no new
dependency, one Settings switch kept in this browser.

Not verified: a physical iPhone and the user's own signed-in Safari; Shift+Insert and Ctrl+Insert
in a Linux or Windows browser by hand (the contributor checked Chrome on Linux; here they are
covered by `web/test/keys.test.mjs`). Known limit: an editor Claude Code opens in its pane
(Ctrl+G) also shows the !, since the hooks still name the agent.
