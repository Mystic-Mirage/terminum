# v0.28.0 — Tip of the day, toasts at the top, no ! over Claude Code's editor

A minor release: a new part of the session list (Tip of the day), a toast moved and one fix.
`terminum upgrade` brings it.

## New

- **Tip of the day** at the foot of the session list, on a computer: one short tip about what
  terminum can do (bookmarks and reminders, the side marks, Files on remote hosts, splits, plans,
  Tailscale…), another each day. Next shows the next one, × closes it until tomorrow, Turn off
  turns tips off; Settings' "Tip of the day" turns them on again. On for a new browser, kept in
  this browser; not on a phone, a touch screen or a window under 560 px tall.

## Changed

- **Toasts show at the top**, 12 px under the terminal's top (under the bookmark bar or the
  "Paused while you select" chip when one shows), where they are read, not over a coding agent's
  input at the bottom. Clicks and taps go through them to the rows under them.

## Fixed

- **The orange ! showed over Claude Code's Ctrl+G editor.** tmux names that pane Claude Code
  while the editor runs (it is in Claude Code's process group), so the page took vim for Claude
  Code's fullscreen TUI. The ! now also needs the terminal's cursor hidden, as Claude Code's own
  TUI keeps it and vim or nano do not; a change counts once it held 400 ms, so a redraw does
  not make it blink.

## Verified

`make check` passes (699 Rust tests, Python, UI and Page unit tests, clippy, the Panel's browser
check 167/167, `web/test/e2e_live.mjs` 233/233 with vim, mc and Claude Code in both of its TUIs:
real Claude Code's Ctrl+G opens vim and the ! goes, back in Claude Code it returns, in Chromium
and WebKit; the Page's browser checks 1659/1659 in Chromium and WebKit at a wide and a phone
size, `scripts/security_check.sh`). Measured first in a private tmux: tmux's
`pane_current_command` stays Claude Code's version while vim or nano runs from Ctrl+G, and its
`cursor_flag` is 0 in Claude Code's TUI, 1 in the editors. The tip was looked at in Chromium and
WebKit, dark and light; the toast at 1400×900 and 390×844, under a shown bookmark bar and with a
phone's Files shown. Reviewed before the release (a pragmatic review and /simplify): the tip
texts checked against the docs, the day rolled in a tab left open, the ! held 400 ms so a redraw
does not make it blink.

Not verified: a physical iPhone and the user's own signed-in Safari. Known limit: an editor that
draws its own cursor (Helix, Kakoune) opened from Claude Code's Ctrl+G still shows the !.
